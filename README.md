# Erhan Dinçer - kişisel site

## Kurulum notları

1. `_config.yml` içindeki `url` alanını gerçek GitHub Pages adresiyle değiştir.
2. `iletisim.md` içindeki form action'ındaki `FORMSPREE-ID-BURAYA` kısmını, formspree.io'da babana ait e-postayla açacağın yeni bir form ID'siyle değiştir.
3. Yeni bir kariyer/görev eklemek için `_data/kariyer.yml` dosyasına yeni bir blok ekle, en üste (en yeni tarih üstte).

## Yerel önizleme

```
bundle install
bundle exec jekyll serve
```
